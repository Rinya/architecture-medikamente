## Аудит мер безопасности (gap-анализ)

| Требование/Практика | Состояние As-Is | Gap |
|--------------------|----------------|-----|
| **ФЗ-152** – согласие, цель, минимизация | Анкета без чек-бокса «даю согласие» | ✅ Создать согласие |
| Определение категорий ПД/PHI | Нет классификатора данных | ✅ Нужен Data Catalogue |
| Тегирование | Нет | ✅ Ввести метки чувствительности |
| RBAC/ABAC | Только AD-группы | ✅ Нужен Fine-grained контроль |
| Шифрование «at rest» | Excel/Scan – не шифруются | ✅ Использовать disk-crypto, DB-TDE |
| Шифрование «at transit» | OLE, TCP/IP (KKM) – нет TLS | ✅ Перевести на TLS 1.3 |
| Аудит действий | Нет журналов доступа к файлам | ✅ Добавить FileAudit/FIM |
| Data Minimisation | Регистрация лишних полей | ✅ Режим «Only as needed» |
| Срок хранения | Данные «вечны» | ✅ Ввести Retention policy |
| Безопасность разработки | Dev-практик нет | ✅ Privacy by Design |
| Backup & Restore | Копии на тот же сервер | ✅ Нужен шифрованный off-site-backup |
| Инцидент-менеджмент | Нет системы SIEM/alerts | ✅ Подключить ELK + filebeat |
